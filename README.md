# Zi Qiang Yang — Academic Website

A responsive, dependency-free academic portfolio built for GitHub Pages.

## Preview locally

```bash
python3 -m http.server 8000
```

Then open `http://localhost:8000`.

## Publish with GitHub Pages

Push the files to the `main` branch, then enable **Settings → Pages → Deploy from a branch**, selecting `main` and `/ (root)`.

## Content sources

Publication titles and profile facts were compiled from the supplied Google Scholar profile. Before publishing, verify the current affiliation, email address, citation count and preferred publication selection.
